# Source-built Activity APK

`build.grease` sequences the maintained application source build. It compiles
the complete ordinary Activity from checked Idriç, compiles the C numerical and
JNI sources with the owned ICK compilers for all three declared ABIs, links
those objects against Android API 23 with NDK 29, and invokes the strict APK
producer. It consumes no APK, candidate DEX or application-library download.

Dependency provisioning is deliberately separate. A host must first build the
exact source revisions in `build-inputs.tsv`, provide the locked independent
Smali/Baksmali jars used to decode and reassemble the compiler output, and
install SDK 35, build tools 35.0.1 and NDK 29.0.14206865. The current hosted
provisioning is in `.github/workflows/idric-formula.yml` and
`.github/workflows/native-android.yml`. These jobs supply exact public source
revisions; their executable caches are acceleration, not application payloads.

Invoke `grease` with the absolute path of `build.grease` and `--help` for the
input order. The explicit repository and toolchain paths make the build
independent of the launch directory. A fresh output directory is mandatory.
The entry verifies each compiler-source checkout before building, rebuilds the
DEX backend in a fresh local source clone with no inherited TTC cache, and leaves separate Activity, native ABI, packaging and aggregate
receipts. Native stages independently bind the actual `cc1`, source/header
bytes, object bytes, ABI, platform linker and resulting shared library.

The producer emits an **unsigned** APK. It does not manufacture a new signing
identity, install on a phone, or turn host compilation into runtime acceptance.
A persistent signer matching the installed package is still necessary for an
update. Installed emulator checks and physical C67 acceptance are separate.

The packaging job also invokes `package.grease` with the trailing profile
`c67` on the same verified DEX and native build evidence. This produces the
aligned unsigned C67 signing input with only `lib/arm64-v8a/libave.so`. The
artifact `explorer-c67-unsigned-signing-input-<source-sha>` carries the
profile, APK digest and ZIP entry evidence for the protected signer. Device
delivery requires an authorized release signature and verification of the
finished APK.

## Migration boundary

`build.sh` is now only a compatibility entry into `build.grease`. The canonical
manifest selects `org.algebraicvarietyexplorer.AVEActivity`, and
`build-values.tsv` owns the preserved
package/version/SDK identity. No root build action compiles the old Android Java
application. The original JVM parser/renderer remain reference oracles through
`examples/autogenerated/original-jvm-reference/build.grease`; their tests do not
qualify the new application package. The old unused Java UI source is reference
material and is not supplied to any candidate compiler or APK producer.

F-Droid must source-build Idriç, the DEX backend, Grease and three ICK compilers
inside its declared buildserver environment. The maintained source recipe and
its scanner acceptance and two disjoint source-build reproducibility runs
remain unqualified until executed in that buildserver. Earlier Java recipe
results and GitHub APK packaging cannot substitute for those results.

The retired Java APK smoke results at API 23 and 35 do not qualify this
replacement. Installed checked-Activity acceptance at API 23 and 35 remains
required and NOT_RUN at this checkpoint; the present installed observer is
bound to API 34. Physical C67 behavior is a further independent requirement.
