# Host qualification integration

Run after the original-lighting reference has emitted the explicit processor
profiles and after the numerical tile kernel gate. Use the same exact-head
source checkout and qualified ICK host compiler as the neighboring gates:

```yaml
- name: Qualify original bounded workers and transactional frame publication
  run: .tools/runtime/.build/grease/bin/grease examples/autogenerated/original-workers/verify.grease "$GITHUB_WORKSPACE" "$GITHUB_WORKSPACE/.ick-host-source" "${{ steps.ick.outputs.compiler }}" "$RUNNER_TEMP/lighting-original-reference" "$RUNNER_TEMP/workers-native-evidence"
- uses: actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02
  if: always()
  with:
    name: surfer-original-workers-${{ github.event.pull_request.head.sha || github.sha }}
    path: ${{ runner.temp }}/workers-native-evidence
    if-no-files-found: warn
```

The existing original-lighting reference artifact retains the four complete
original processor-profile pixel tables. The worker evidence hashes those exact
inputs, `surfer_original_workers.inc`, the session owner, all numerical sources
and the actual compiler/cc1. It retains decoded candidate ARGB records,
four compiled-mutant diagnostics and sanitizer outputs. `result.tsv` is written
only after every gate, including actual leak checking, succeeds.

Production source/object/profile packaging must also retain the new included
`native/surfer_original_workers.inc` as a material numerical input. The consumer
does not compile a separate worker translation unit: that include belongs to
the existing `surfer_render_session.c` object and its declared ICK compile.
