# Observe the actual prepared-surface transfer

The candidate is the application's real Idriç formula→preparation→ordered
expansion→array-fill→JNI path. The independent runner obtains its actual
positive Int64 handle and reads the native snapshot through the existing
test-only `CopiedSurfaceObserver`. It formats the four observed ranges in their
existing order and compares them with the unchanged original renderer's getters
and `Expand`, using `OriginalExpansionOracle`.

No observer sorts terms, computes derivatives, substitutes coefficients or
constructs a candidate surface. Field2 is transported as raw coefficient bits;
fields3/4/5 are the copied x/y/z exponents. Family degree and term counts are
observed separately. An elementary x-plane has fixed expectations in addition
to the original-program comparison, so swapped labels cannot qualify together.

The candidate class and native observer must resolve the same loaded test
library and registry. The library path property is set before initializing the
source-generated class; that class's own `<clinit>` loads the library. Observer
and candidate classes share one process/class loader. Production library builds
exclude these observer declarations and allocation hooks.

The runner covers the seven closed presets, the user's quartic, cancellation,
reciprocal rounding and Kahan-sensitive collection. The actual producer binds
no parameters; missing-parameter behavior is tested as an explicit error rather
than claiming positive binding acceptance. Each handle is observed, released,
checked stale and checked against double release. Successful/failing source
replacement cycles must drain all native allocations. Detailed concurrent
borrow/retirement remains the separate native receiver qualification; the
private `NativeSurface` constructor is not exposed for testing.

Source validation is required to fail before JNI, with zero JNI allocation
attempts. Both temporary JNI allocations and both native-store allocations are
failed through test-only hooks while executing the actual generated producer.
Errors must be reported, existing separately held handles must remain usable,
and temporary/snapshot/borrow/store-allocation counts must return to zero.

Two source mutations alter the real producer: one writes wrong coefficient
values and one fills the x-gradient range from the y-gradient. Both must fail
the same independent field/bit observer with designated exit80. Candidate
instructions always come from the maintained compiler; Smali supplies only
independent observation and original-program access.
