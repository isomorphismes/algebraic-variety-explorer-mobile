# algebraic-variety-explorer-mobile
visualize 3-letter polynomials on your phone! this is a port of Christian Stouffer's Oberwolfach ray tracer SURFER to run on mobile devices


this entire app was designed by a large language model, chat GPT 5.6 Sol. the original Ray tracer was written by Christian Stouffer and the Oberwolfach Institute.

I make no representations as to the correctness of this software. I likely will never even inspect the code. it is posted purely for the convenience of myself and anyone else who cares to take the risk for the convenience of playing around with algebraic varieties on your phone.
